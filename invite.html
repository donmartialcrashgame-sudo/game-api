How invitations work

1. Tap Select From Contacts.
2. Choose one or more contacts in the device's native picker.
3. Game API displays the selected contact locally on this page.
4. Choose Share, SMS, or Email to open the appropriate app with the invitation prepared.

Game API does not need to read your entire address book. The Contact Picker returns only selected contacts and requested fields.
